Comprobar el funcionamiento del sistema de administración de inventario mediante pruebas de sus principales funcionalidades.

3. Descripción de las pruebas

- Registro: se comprobó que los productos se agregaran correctamente.
- Actualización: se verificó la modificación de los datos de los productos.
- Entradas: se comprobó el aumento de las existencias.
- Salidas: se verificó la disminución de las existencias.
- Búsqueda: se comprobó la búsqueda por nombre, categoría y proveedor.
- Stock mínimo: se verificó la identificación de productos con existencias bajas.
- Eliminación: se comprobó que los productos seleccionados fueran eliminados.
- Validaciones: se verificó el control de datos incorrectos y cantidades no permitidas.

Las capturas de pantalla de las pruebas realizadas se encuentran en la carpeta "evidencias".

5. Conclusión

Las pruebas permitieron comprobar las funcionalidades principales de InventarioApp y verificar el comportamiento del sistema durante la administración de productos y el control de existencias.
